# Journey Earth imagery

`earth-blue-marble.webp` is a resized and WebP-compressed version of NASA's
Blue Marble Next Generation, June 2004 base map (5400 × 2700 → 2048 × 1024).

Credit: **NASA Earth Observatory**. Imagery produced by Reto Stöckli,
NASA Earth Observatory (Goddard Space Flight Center).

- Collection: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/
- Source image: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/june/world.200406.3x5400x2700.jpg
- NASA image/media guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/

The globe is rendered locally with the site's existing Three.js r149 (MIT).
No external service, generated illustration, or additional rendering library
is used. NASA does not endorse this website.
