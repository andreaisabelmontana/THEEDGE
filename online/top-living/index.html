Top Living

Designed and developed Top Living’s real estate website from interface design through implementation. Integrated the DOMUS API for property listings and search filters, added interactive maps, and built the PHP backend and frontend. The site is hosted on GoDaddy.

01

The business need

Launched Top Living’s digital presence alongside the new Bogotá real estate agency in 2020, creating a professional place to build trust, showcase available properties and connect buyers and renters with the team.

02

My role

I designed and developed the website end to end, including the visual interface, PHP backend and JavaScript, HTML and CSS frontend. I also researched the user experience and created a separate mobile prototype in Adobe XD.

03

The technical approach

I integrated the DOMUS API with property search and detailed listing pages, then added map displays, enquiry forms and viewing requests. Filters for location, price and property features help visitors narrow their search. The website is hosted on GoDaddy.

04

Why it matters

Since launch, the website has become a well-known digital reference point for Top Living, including for the Netherlands Embassy. It now supports a live catalogue of 124 property listings (as of 22 September 2026), powered by DOMUS so the team manages inventory in one place. Top Living has also grown an organic Instagram community of 11,000+ followers — evidence of the public presence built around the brand.
