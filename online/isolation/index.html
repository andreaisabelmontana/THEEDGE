    How to play

    You move first. Pick a highlighted square: two squares in one direction, one in the other. You can jump over pieces and burned squares, but can only land on empty squares. Each square you leave burns permanently. The first player with no legal move loses. Use the arrow keys to explore the board and Enter or Space to play.

    Game logic

    1. Find a legal knight move

    Each square has a list of in-bounds knight jumps. Only empty destinations are available.

    const moves = (b, p) =>
  ADJ[p].filter(i => b[i] === EMPTY);

    2. Burn the old square

    Each move permanently burns the square you left, then hands the turn to your opponent.

    board[pos[turn]] = BURN;
board[dest] = turn;
pos[turn] = dest;
state.plies++;
state.turn = 3 - turn;
if (!moves(board, pos[state.turn]).length) state.winner = turn;

    3. Pick the computer’s move

    Strategic mode tests each move with four-ply alpha-beta search. At the depth limit, breadth-first search estimates territory. During search, the computer skips branches that can no longer change the result.

    const candidate = -search(opp, dest, d - 1, 3 - mark, -beta, -alpha);
b[dest] = EMPTY;
b[own] = mark;
value = Math.max(value, candidate);
alpha = Math.max(alpha, value);
if (alpha >= beta) { cutoffs++; break; }
